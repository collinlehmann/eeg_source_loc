# EEG Source Localization Pipeline

MATLAB toolbox for individualized-MRI EEG source localization with cortical and subcortical source spaces.

This repository is being scaffolded from the project specifications. The implementation preserves FieldTrip-compatible data contracts, cached precompute artifacts, pluggable inverse methods, FEM engine adapters, provenance, and headless batch execution.

See `docs/ARCHITECTURE.md` and `docs/OPEN_ITEMS.md` for the current implementation boundary and unresolved scientific decisions.

For deterministic synthetic end-to-end validation (no FieldTrip required), see `docs/SYNTHETIC_VALIDATION.md`.
